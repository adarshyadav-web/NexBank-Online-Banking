# NexBank Online Banking

A professional financial dashboard UI featuring account summaries, balance trends, and transaction history management.

## 🚀 Features

- **Financial Stats Card**: Quick view of balance, income, and expenses.
- **Transaction Search**: Real-time filtering of account activities.
- **Modern Sidebar**: Clean navigation for banking services.
- **Trend Indicators**: Visual feedback on financial performance.

## 🛠️ Technologies Used

- **HTML5**, **CSS3**, **JavaScript**
